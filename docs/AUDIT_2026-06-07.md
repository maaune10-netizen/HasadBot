- **Total tables:** 28

### Schema Duplication Issues

| Table | Defined In | Count |
|---|---|---|
| `payment_requests` | database.py:162, database.py:656, handlers/subscriptions.py:60 | **3×** |
| `button_clicks` | database.py:249, logger.py:487 | 2× |
| `all_messages` | database.py:419, database.py:2072 | 2× |
| `knowledge` | database.py:531 (sync), database.py:546 (async) | 2× |
| `student_cvs_v2` | database.py:458, main.py:571 | 2× |

### Connection Pool Problems
- `get_pooled_connection()` / `release_pooled_connection()` exist but **never called by any function**
- All 79 data functions use the **single shared `_connection`** → no real concurrency
- `_pool_lock` held across `await conn.execute()` → serializes the entire pool
- `row_factory = aiosqlite.Row` repeatedly reassigned (18+ places) → race condition

### FK Enforcement
- `PRAGMA foreign_keys=ON` only in `hasad.db` (database.py:76)
- **Disabled** in `harvest_cv.db` and `hasad_knowledge_base123.db`
